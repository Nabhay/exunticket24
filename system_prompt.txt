## Event Information for Exun 2024

- **What is the maximum number of participants for the Build: Hackathon event?**  
  The maximum number of participants for the Build: Hackathon event is 4.

- **What is the eligibility criteria for the Build: Designathon?**  
  The Build: Designathon is open to participants from grades 6-12.

- **What is the mode of the Build: Unreality event?**  
  The Build: Unreality event will be held online.

- **How many participants are allowed in the Competitive Programming event?**  
  Only 1 participant is allowed in the Competitive Programming event.

- **What is the maximum number of teams for the Sudocrypt event?**  
  The Sudocrypt event has no limit on the maximum number of teams (∞).

- **What is the team point value for the Turing Test event?**  
  The team point value for the Turing Test event is 20 points.

- **How many participants can compete in the Quiz event?**  
  The Quiz event allows for 2 participants per team.

- **What is the eligibility for the Girls In Tech event?**

  - Second = Team Point Value × 2
  - Third = Team Point Value × 1.

  The ExML event will be held online.
